【鋼筆控】品相術語：NOS、二手、修復品與展示品

逛老筆拍賣會看到 NOS、NOSM、Restored、Display Only、MINT……這些英文縮寫到底差在哪？本文整理鋼筆收藏圈最常見的品相術語，讓你下次看商品敘述不再霧煞煞。

#品相#術語#NOS#二手#收藏

進到老筆收藏領域，你會看到賣家在商品標題上掛滿各種英文縮寫：NOS、NOSM、MINT、Restored、Display Only……這些詞並不是裝飾，而是業界用來概括一支筆「過去歲月」的快速標籤。看懂這些術語，是避免買錯、買貴、買到預期外狀況的基本功。

為什麼要分這麼細

新筆市場幾乎沒有「品相」問題——你看到的新筆就是新筆。但老筆市場每一支都是獨一無二的：有的從未被人寫過、有的被用了幾十年、有的被拆過修過。若沒有統一術語，賣家說「狀況很好」，買家心裡想的「很好」可能完全是另一回事。

最核心的幾個品相詞

術語原文／意思實際意義
NOSNew Old Stock全新庫存品，從未使用，但存放多年
NOSMNew Old Stock Mint庫存保存極佳，接近剛出廠狀態
MINT如同鑄幣般新近全新、幾乎無使用痕跡
Used使用過一般二手，視描述進一步分級
Restored已修復更換過密封件、清洗、整理後可使用
Display Only僅供展示不可上墨、內部狀況不明或已損壞
As Found保持發現時狀態未清洗未修，可能需自行整理
注意：這些詞在不同賣家口中標準可能不一樣。同樣寫「NOS」，甲賣家可能真的從未上墨，乙賣家可能只是「看起來像新的二手」。務必配合實際照片與影片確認。

NOS：老筆玩家最愛的「時光膠囊」

NOS（New Old Stock）指的是當年生產完、一直放在倉庫或櫥櫃裡、從未被拿出使用過的庫存新筆。它的魅力在於：

  • 筆尖幾乎未磨損：保持工廠出廠時的狀態
  • 筆身毫無刮痕：沒有被日常使用的痕跡
  • 保持時代的完整風貌：常連同原盒、保證書、當年的包裝紙一起出土

但請注意，「未使用」不代表「狀況完美」。存放了五六十年的橡膠密封件，即使沒裝過墨水，也可能自然老化龜裂。所以一支 NOS 筆，往往仍需更換內部橡膠零件才能安心使用。

二手筆：使用過但狀況尚可

Used 是最寬泛的標籤。它可能涵蓋：

  • 輕度使用、幾乎看不到痕跡的「接近新」
  • 正常使用、有些刮痕但功能完好
  • 明顯使用痕跡、鍍金磨損、但依然好寫

買二手筆時，不要只看「Used」這個字，要仔細看賣家怎麼描述：筆尖磨損程度、筆身刮痕、鍍層褪色、筆蓋鬆緊、上墨功能是否正常。

Restored：被專業修復過的老筆

老筆經過幾十年，密封橡膠必然老化，多數能寫的老筆都是 Restored 過的。Restored 通常包括：

  • 更換墨囊、活塞、密封環等橡膠零件
  • 拆筆、清洗筆舌與上墨機關
  • 筆尖檢查與基本調校

一支有完整修復紀錄、且修復師傅有口碑的 Restored 老筆，比「從未修過但內部未知」的老筆更安心。

提示：買 Restored 老筆，務必問清楚「修了哪些東西、用的是原廠件還是替代件、何時修的」。這些資訊會直接影響這支筆的後續使用與價值。

Display Only 與 As Found：入門者的地雷

  • Display Only（僅供展示）：賣家明白告訴你，這支筆現在無法上墨，可能內部損壞、缺零件、或筆身脆化。它適合拿來陳列、拍照，不適合想拿來寫字的人。新手看到便宜的 Display Only 老筆，務必克制。
  • As Found（保持發現時狀態）：通常指出自拍賣、庫存清倉、藏家過世後流出的「原始狀態」。賣家沒有清洗、沒有測試、沒有修復，你買到的是「自己要冒險整理」的筆。

如何使用這些術語保護自己

  1. 不要只看標籤，要看照片：鏡頭要涵蓋筆尖、筆身、筆蓋、上墨機關、原盒
  2. 請賣家提供上墨測試影片：可寫的筆應該有流暢出墨的實證
  3. 要求書面描述細節：鍍金是否褪色、筆尖是否修磨過、原盒是否齊全
  4. 比對同型筆行情：同品相、同年份的合理價位心裡要有底

常見問題

多半不行。雖然外觀全新，但內部橡膠存放了幾十年，幾乎都已老化。直接灌墨水可能漏墨。建議先檢查或更換密封件再使用。

剛好相反。一支狀況良好、有專業修復的老筆，比「未修但可能故障」的筆更有價值——因為它可以安心被使用。真正貶值的是業主自行粗暴拆解、換件失敗的筆。

除非你自己有修復能力與零件來源，否則不建議新手下手。多數 Display Only 筆的問題，整理成本往往超過筆本身價值。

沒有絕對。MINT 強調「像新的一樣好」，可能是二手保存極佳；NOS 強調「從未使用過」。對收藏者來說，有完整包裝與保存故事的 NOS，通常更具收藏意義。
