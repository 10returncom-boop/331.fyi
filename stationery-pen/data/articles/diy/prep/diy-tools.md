# DIY 工具清單與安全提醒

自己動手修鋼筆，是筆迷圈最有成就感、也最容易翻車的一條路。一支本來好好的筆，可能在你好奇拆解後再也組不回去。與其靠運氣，不如先把工具備齊、把安全觀念建立起來。這篇文章是 DIY 的起點：告訴你哪些工具真的需要、各自做什麼用，以及在開始任何動作之前，哪些底線務必守住。

## 心態先就位

在談工具之前，先記住一句話：**鋼筆是精密小器械，不是塑膠模型。** 它的筆尖縫以公釐計算，筆舌溝槽細如髮絲，一個用力過猛的動作就可能造成不可逆傷害。DIY 的第一原則不是「把它修好」，而是「先不要把它搞壞」。

> 注意：高價筆、限量筆、有紀念價值或難以取得零件的筆，**不適合當練習對象**。第一次動手，請用便宜的入門筆或報廢筆操刀，累積手感後再碰好筆。

## 基礎工具清單

以下是新手最實用的工具，不需要一次買齊，可隨進度添購：

| 工具 | 用途 | 使用眉角 |
| --- | --- | --- |
| 矽膠工作墊／防滑墊 | 防止筆件滾落、刮傷 | 選有止滑紋理的軟墊 |
| 鑷子（鈍頭） | 夾取小零件、舊密封圈 | 不要用尖嘴夾筆尖，以免刮傷 |
| 橡膠防滑墊／夾 | 轉開緊的筆蓋、筆桿 | 增加摩擦力，避免硬轉打滑 |
| 超細砂紙（微米級） | 微量打磨筆尖 | 只用於進階打磨，新手別急著用 |
| 放大鏡／手機微距鏡頭 | 觀察筆尖縫、銥粒 | 看得清楚才知道問題在哪 |
| 溫水、棉花棒 | 清洗筆舌與縫隙 | 棉花棒可伸進狹小空間 |
| 鋼筆專用矽脂 | 潤滑密封圈、螺紋 | 用量要極薄，勿沾到筆舌出墨處 |
| 手套（防滑薄款） | 增加握感、防手汗 | 拆裝時穩定施力 |

## 進階才需要的工具

等你熟悉基礎操作後，再考慮添購：

- **筆尖專用鉗（包膠）**：拆裝筆尖時夾持用，普通鉗子會刮傷筆尖
- **各尺寸 O 型環與密封圈**：備品，用於更換老化密封件
- **研磨膏／拋光膏**：筆尖微調與拋光
- **小型燈具與支架放大鏡**：長時間作業時減輕眼睛負擔

> 提示：工具不在多，在於「對的工具做對的事」。用尖嘴鉗硬夾筆尖、用一般砂紙亂磨，是初學者最常見的致命錯誤。寧可多花時間找正確工具，也不要將就。

## 安全守則：動手前必讀

> 注意：鋼筆 DIY 常見的不可逆損傷包括——筆尖分岔或刮傷、銥粒崩落、筆舌破裂、螺紋滑牙、密封圈弄丟或裝錯、筆桿裂開。任何動作前都要假設「這一步做錯，筆就報廢」。

務必遵守以下原則：

1. **先拍照再拆**：每拆一步就拍照記錄位置與方向，組回來才有依據。
2. **小零件集中放**：密封圈、彈簧等小零件放在小盒子裡，以免彈飛找不到。
3. **施力要軟**：筆件多為樹脂或薄金屬，硬轉硬撬必壞。轉不動時先想「是不是方向錯了」，而不是更用力。
4. **保持桌面空曠**：避免水杯、工具與筆件混在一起，打翻墨水或壓到筆尖都是常見意外。
5. **隨時可以停**：卡住、懷疑、不確定時就停下來，上網查或問前輩，不要硬來。

## 練習順序建議

對初學者來說，建議按照由淺入深的順序累積經驗：

1. 先練習**清洗與拆解重組**一般筆（見〈上墨系統清潔重點〉）
2. 再嘗試**更換密封圈或墨囊吸墨器**這類低風險動作
3. 熟悉後才碰**筆尖拆裝與簡單打磨**（見〈筆尖拆裝與簡單打磨〉）
4. 彈尖調整與上墨系統維修屬於**進階操作**，建議看過足夠實例再上手

## 常見問題

**Q：一定要買很貴的工具才能開始嗎？**
A：不用。一塊防滑墊、一把鈍頭鑷子、一支放大鏡和溫水，就能開始清洗與簡單保養。昂貴工具是進階後才需要。

**Q：我可以直接對好筆動手練習嗎？**
A：強烈不建議。高價或稀有筆的零件難取得、修復成本高，請用便宜筆練手。這不是小氣，是保護你的投資。

**Q：DIY 失敗了怎麼辦？**
A：先停下、不要繼續拆。很多問題其實交給專業維修就能解決；繼續硬修往往只會把小問題變成大損傷。

**Q：矽脂可以用一般黃油替代嗎？**
A：不行。一般潤滑油可能與筆的塑膠、墨水不相容，甚至腐蝕膠件。請使用鋼筆專用矽脂，並且只用在密封圈與螺紋，別碰筆舌出墨路徑。
