# 二手庫存老筆選購檢查清單

二手老筆的魅力，在於用中價位買到當年旗艦的工藝；但它的風險也同樣經典——橡膠老化、筆尖崩壞、上墨系統卡死、被人當新筆賣。新手最常見的下場，就是被一張漂亮的筆身照片說服，下標收貨後才發現根本寫不出字。本文提供一張逐項檢查清單，讓你在匯款前（或收貨驗貨時）把每個環節都檢查過一輪。

> 提示：這份清單適用於網購二手老筆的「開箱驗貨」與「賣家問答」兩個階段。每一項都建議要求賣家提供對應照片或影片，不要只看主圖。

## 第一關：筆身外觀

老筆的外觀決定它的品相分級，也決定日後整理的難度。

| 檢查項目 | 要確認什麼 | 紅旗（看到就考慮放棄） |
| --- | --- | --- |
| 筆身裂縫 | 光線下斜看筆桿有無髮絲裂 | 明顯裂縫、修補痕跡 |
| 賽璐珞狀態 | 有無龜裂、變色、「綠鏽」般的腐蝕 | 賽璐珞起粉、開裂 |
| 筆蓋密合 | 轉緊後是否晃動、對齊商標 | 筆蓋鬆脫、轉不到底 |
| 筆夾 | 是否牢固、彈性是否正常 | 筆夾鬆脫、鍍層大片脫落 |
| 鍍層 | 金套、銀夾磨損程度 | 鍍層鏽穿、露出底材 |
| 商標刻印 | 字跡是否清晰 | 商標磨平到難以辨識 |

> 注意：賽璐珞是老筆最迷人也最脆弱的材質。如果賣家照片看起來筆身「霧霧的、有粉末感」，那是賽璐珞老化（又稱鱗化）的開始，這種筆再便宜都不要碰。

## 第二關：筆尖狀態

筆尖是老筆靈魂，也是最容易被賣家用「寫起來很順」帶過的地方。務必要求賣家提供：

- **筆尖正面特寫**：看銥粒形狀是否完整、有無一邊被磨歪
- **筆尖側面特寫**：看銥粒有無缺角、崩裂
- **筆尖縫**：看中縫是否對齊、有無變形打開
- **彈性測試影片**：輕壓筆尖看縫隙開合是否對稱（彈性尖老筆必看）

| 筆尖問題 | 外觀特徵 | 處理難度 |
| --- | --- | --- |
| 銥粒磨歪 | 一邊高、一邊低 | 需重磨，費用高 |
| 崩銥 | 銥點有缺口或缺失 | 幾乎無法修，列入拒絕往來 |
| 筆尖縫打開 | 中縫變寬、對不齊 | 需矯正，有風險 |
| 筆尖變形 | 整隻尖歪斜 | 嚴重變形建議放棄 |
| 鏽蝕 | 金尖表面有紅點黑斑 | 輕微可清，嚴重放棄 |

> 注意：「寫起來很順」是賣家用語，不是技術規格。順不順要你自己試。網購老筆，務必選有開箱鑑賞期、可退貨的賣家。

## 第三關：上墨系統

老筆最容易死在這一關。現代筆是活塞或卡墨，結構單純；老筆常見的槓桿式、按鈕式、半彎式上墨，全靠一條老橡膠墨囊撐著，那條橡膠幾乎都超過半個世紀了。

| 上墨類型 | 主要老化點 | 檢查重點 |
| --- | --- | --- |
| 卡墨／現代吸墨器 | 間歇性滲墨 | 換新墨囊就好，風險低 |
| 活塞上墨 | 活塞乾澀、密封圈硬化 | 轉動是否順、有無阻力忽大忽小 |
| 槓桿／按鈕／半彎 | 內部橡膠墨囊龜裂 | 幾乎一定要換墨囊 |
| 真空上墨 | 內部機構卡筍磨損 | 拆解檢查風險高 |

> 警告：任何古董上墨筆，假設它的橡膠已經失效是合理預設。買回來第一件事就是送修換墨囊，這筆預算要先算進去。如果賣家宣稱「還能上墨」，要求看實際吸墨的影片，不要只聽說。

## 第四關：氣密與乾筆

老筆放了幾十年，筆蓋密封圈可能硬化、筆舌可能卡了乾墨。檢查重點：

- 請賣家描述「上次清洗時間」
- 開蓋後聞筆尖有無乾涸墨水的酸味或霉味
- 問清楚「最後一次實際書寫是什麼時候」
- 收到貨後，先泡溫水半小時，再試上墨

老筆的「乾筆」（筆尖縫被陳年墨水黏死）非常常見，多數泡水就能鬆開；但如果是筆舌內部結晶，可能要超音波清洗才能救。

## 第五關：證明與來源

最後一關，是確認這支筆的身分與來路：

| 確認項目 | 理想狀態 |
| --- | --- |
| 原盒與保證書 | 齊全，編號對得上 |
| 購買憑證 | 發票或購買紀錄 |
| 賣方評價 | 長期經營、鋼筆專賣、評價數百則以上 |
| 退貨政策 | 至少七天鑑賞期 |
| 是否為改筆／組裝筆 | 賣家誠實告知改裝歷史 |

> 小知識：「NOS」（New Old Stock，庫存新品）老筆聽起來誘人，但放了五十年的 NOS，內部橡膠其實也老了。NOS 不等於免檢查，只是筆身外觀通常較好。

## 開箱驗貨流程（收貨當天）

貨送到之後，建議照這個順序驗：

1. **不拆墨**，先對外觀：對照賣家照片，確認沒有額外損傷
2. **拆筆聞味**：有無霉味、溶劑味
3. **泡溫水**：筆尖筆舌泡半小時，看水會不會變色
4. **試上墨**：用最便宜的藍黑墨試寫，不要直接上你心愛的墨水
5. **寫滿一頁**：各角度畫圓、寫字，確認無飛白、無斷墨
6. **不對就退**：三天內發現問題，立刻聯絡賣家

## 常見問題

**Q：第一次買老筆，從什麼等級開始比較安全？**
A：從 1960 年代以後、現代上墨系統（活塞、卡墨）的筆開始。古董槓桿筆雖然迷人，但橡膠更老、維修更貴，等你踩過幾次坑再碰。

**Q：賣家不給影片、只給幾張照片，可以買嗎？**
A：不建議。老筆交易誠實是基本門檻，連影片都不願意拍的賣家，背後通常有不想讓你看到的東西。

**Q：老筆買回來發現寫不出來，是我被騙了嗎？**
A：不一定。多數老筆寫不出來只是乾筆，泡水清洗後就能救。真正的壞筆是筆尖崩裂、筆身裂縫、上墨機構卡死到拆不開那種。

**Q：老筆需要先送檢再買嗎？**
A：高價筆（超過你心理門檻很多）可以考慮先請信任的老筆商或維修師傅鑑定。低價筆自己照清單檢查即可。

**Q：買回來的老筆，可以直接上貴重墨水嗎？**
A：絕對不要。先便宜墨試筆一兩週，確認沒有漏墨、沒有腐蝕疑慮，再換好墨。否則萬一筆內部有問題，整瓶好墨都賠進去。
