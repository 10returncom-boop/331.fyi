# 商品分類導覽：從鋼筆到紙品

走進i文具控，或上它的線上商城，商品琳瑯滿目：這麼多東西到底怎麼分類？這篇導覽把它的商品線整理成一張表，讓你無論是想買一支筆、找一瓶墨水，還是添一本筆記本，都能一秒定位。

## 商品分類總覽

| 分類 | 內容 | 適合誰 |
| --- | --- | --- |
| 鋼筆 | 入門、日常、高階與限量筆款 | 想開始手寫或升級的人 |
| 原子筆 | 免上墨、免保養的便利書寫 | 追求零負擔日常書寫 |
| 鋼珠筆 | 滑順、速乾、好攜帶 | 常在外、講求乾爽 |
| 墨水 | 染料、顏料、特色與限定墨 | 鋼筆使用者與玩色玩家 |
| 自動鉛筆 | 設計款、繪圖用筆 | 畫圖、寫草稿、愛鉛筆手感 |
| 配件 | 吸墨器、墨囊、筆套、筆立、清潔用品 | 既有鋼筆需要補充耗材 |
| 書法 | 書法鋼筆、毛筆、墨條與字帖 | 練字與書法愛好者 |
| 紙品 | 鋼筆專用筆記本、信紙、色卡 | 講求書寫質感的人 |
| 蘸水筆 | 蘸水筆尖與筆桿 | 練英文書法、花體字 |

## 鋼筆：壓軸主力

鋼筆是整個商品線的核心。從輕巧好上手的入門款、天天用的日常筆，到工藝精緻的高階與限量款，應有盡有。挑鋼筆時建議回頭參考「依書寫習慣」與「依預算」的邏輯，先想清楚用途再看分類，效率最高。

## 墨水與紙品：好筆的最佳搭檔

一支好筆需要好墨好紙才能完全發揮。墨水分類裡涵蓋染料、顏料與各國特色墨；紙品則網羅鋼筆專用筆記本與信紙——特別推薦在意暈墨、透背的人，認真挑一本會吃墨又不洇的紙。

> 提示：第一次在店裡湊齊「筆＋墨＋紙」時，建議直接請店員現場試寫給你看，一次驗證三方搭配，比分開買回家才發現不合適省事得多。

## 配件：常被忽略卻很重要的一環

很多人只盯著筆看，但其實配件才是讓筆用得長久的關鍵：

- **吸墨器／墨囊**：上墨的耗材，規格要對應自己的筆款
- **筆套／筆袋**：保護筆身、防刮防壓，隨身攜帶必備
- **清潔用品**：洗筆杯、專用清潔液，定期保養用
- **筆立、展示架**：讓愛筆在書桌上有個好位置

## 原子筆、鋼珠筆與自動鉛筆

不是每個場景都適合鋼筆。需要快速簽名、隨手記錄、不願意保養時，原子筆與鋼珠筆就是最務實的選擇；自動鉛筆則適合畫圖、打草稿與習慣鉛筆質感的人。把這些都放在同一間店，好處是你能一次比較不同書寫工具的手感。

## 書法與蘸水筆

對想認真練字的人，這塊分類提供從入門書法鋼筆、毛筆到字帖的完整路徑；蘸水筆與筆尖則是想鑽研英文花體、書法字的玩家會感興趣的領域。它們和鋼筆是不同的書寫邏輯，但同樣迷人。

## 常見問題

**Q：第一次逛，應該從哪個分類開始看？**
A：如果你是衝著鋼筆來的，先看「鋼筆」確定需求筆款，再到「墨水」「紙品」補充搭配；只想添日常文具，則可從「原子筆／鋼珠筆」或「配件」下手。

**Q：店裡的紙品一定適合鋼筆嗎？**
A：分類上的紙品多以鋼筆書寫需求挑選，但不同紙吸水性仍有差。最好請店家推薦或現場試寫，確認不會暈墨再買。

**Q：可以線上買，然後再到店試寫嗎？**
A：可以，但更建議的順序是「先到店試寫確認手感，再線上或店下單」，避免買回家才發現不合手。

**Q：買鋼筆一定得同時買墨水嗎？**
A：不一定，但鋼筆離開墨水就無法書寫。若你已有現成墨水，只需確認新筆適用的上墨規格即可。
