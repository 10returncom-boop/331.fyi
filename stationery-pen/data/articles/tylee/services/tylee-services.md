# 實體店、試寫與維修服務指南

知道i文具控在做什麼之後，下一個問題通常是：「那我實際走進去，能用到哪些服務？」這篇文章把到店體驗拆開——從最基礎的試寫挑筆，到進階的筆尖調校、清洗維修與客製諮詢，讓你進門前心裡有張地圖。

## 實體試寫：最重要的一項服務

對多數人來說，到店的核心目的就是**試寫**。好的試寫體驗包含幾個環節：

- **現場備筆**：把不同品牌、不同筆尖尺寸的筆款實際擺出來
- **備齊墨水**：多款墨水隨時可上筆試色
- **試寫紙張**：準備不同粗細感受的試寫紙
- **店員引導**：先問你的用途與預算，再帶你對照試寫

建議你試寫時，用**自己平常的字速與筆觸**去寫，而不是隨便畫兩條線。畫圓圈、寫幾個中文字、試試快速書寫，才能真正比較出手感差異。

## 筆尖調校：把不順的筆調順

新筆偶爾會有小脾氣：刮紙、下墨太兇、出水太保守、書寫角度怪。這些問題很多時候不靠換筆，而靠**筆尖調校（Nib Tuning）**解決。常見的調校項目包括：

| 症狀 | 可能調整方向 |
| --- | --- |
| 刮紙、沙沙作響 | 修磨銥粒接觸面，讓它更圓滑 |
| 下墨太兇、容易暈 | 微調筆尖縫與供墨 |
| 下墨太保守、斷墨 | 微開筆縫、改善導墨 |
| 左側或右側刮紙 | 校正筆尖對齊與打磨角度 |

> 注意：筆尖調校是專業技藝，屬於「動銥粒、動筆縫」的精密工作。觀念上正確的微調可以讓筆脫胎換骨，但暴力打磨則可能讓一支好筆報廢——交給有經驗的師傅最穩。

## 清洗與保養諮詢

你可能聽過「鋼筆要定期洗」，但實際怎麼洗、多久洗一次、卡在筆舌的墨渣怎麼清，新手常一知半解。到店可以：

- 請店員示範正確的拆解與清洗流程
- 確認自己手上這支筆適合多久洗一次
- 請教墨水更換、長期收藏的保存方式

對長期攜帶、天天使用的筆，定期保養諮詢能大幅延長它的壽命。

## 客製與選筆諮詢

若你有明確的預算、用途或收藏目標，也可以預約到店諮詢：

- 依你的書寫習慣推薦筆尖粗細與筆款
- 依預算規劃入門、中階到旗艦的選擇
- 討論訂製筆身、特殊打磨、刻印等客製項目

這類深度諮詢通常比純試寫花更多時間，建議事先聯繫門市預約。

## 到店前的準備清單

為了讓一次到店物超所值，建議出發前想清楚這幾件事：

1. **用途**：日常筆記？練字？簽名？收藏？
2. **預算**：心願區間大概落在哪
3. **慣用紙**：可以帶自己常用的筆記本去試寫
4. **現有問題**：如果是送修或調校，把症狀想清楚（什麼時候刮、哪個角度澀）

## 常見問題

**Q：試寫要收費嗎？**
A：試寫本身通常是免費的體驗服務，這是筆店吸引你認識產品的方式。你儘管在試寫紙上盡情比較，不用有壓力。

**Q：新筆一定需要調校嗎？**
A：不一定。多數市售新筆出廠時已調校完成，好寫就不用動。只有在你實際試出刮紙、出水不順等具體症狀時，才需要考慮。

**Q：帶舊筆去洗或調校可以嗎？**
A：可以。很多店家也接受外部送修與保養，建議去之前先聯繫確認預約、天數與收費。

**Q：調校過的筆會不會影響保值？**
A：專業、輕微的手感微調對多數日常使用筆是加分；但若動到收藏級老筆，則建議先與店家確認對價值的影響。
