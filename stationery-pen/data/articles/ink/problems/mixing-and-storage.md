# 墨水混調禁忌與儲存指南

把兩瓶喜愛的墨水倒在一起，調出舉世無雙的專屬色，是許多玩墨玩家的浪漫。但混調是門分寸學問：同類、同酸鹼、同體系的墨水相安無事，跨界亂攪則可能一夜之間絮凝發臭、把筆堵死。這篇文章講清楚混調的安全界線，以及開瓶後墨水到底該怎麼放。

## 混調的黃金原則：同類、同體系

能不能混，先問三個問題：

1. **是不是同一類墨水？**（染料配染料最安全）
2. **酸鹼值是否接近？**（避免酸鹼對衝）
3. **是不是同一廠牌、相近配方？**（分散劑、潤滑體系相容）

最安全的混調，是**同廠牌、同為染料系、色系相近**的墨水，例如把兩個藍色調出自己偏好的藍。這類實驗風險低，失敗了大不了倒掉。

## 絕對不要混的組合

| 組合 | 風險 |
| --- | --- |
| 染料墨 + 顏料墨 | 分散劑被破壞，顏料絮凝沉澱 |
| 任意墨 + 鐵膽墨 | 鞣酸與其他色素可能反應、生鏽 |
| 酸性墨 + 鹼性墨 | 酸鹼中和，產生沉澱或改變性質 |
| 含珠光微粒墨 + 一般墨 | 微粒聚集、加速堵筆 |

> 注意：混調實驗請**絕對不要直接倒回新鮮墨水原瓶**，也不要直接灌進你最寶貴的收藏筆。用小空墨水瓶調，先在紙上試寫、觀察一兩天有無沉澱變質，再決定要不要入筆。

## 混調的正確姿勢

如果你想安全地玩色，建議照這個流程：

1. 準備乾淨的小空瓶（附蓋）
2. 先少量混合，比例從淺色基墨加點綴色開始試
3. 搖勻後靜置觀察 24–48 小時，看有無沉澱、分層、變臭
4. 沒問題再用普通試寫筆試寫，觀察流動與色澤
5. 滿意了才正式使用，並記錄配方比例

## 墨水為什麼會變質

墨水是水基有機液體，開瓶後隨著時間與環境變化，可能出現：

- **水分蒸發**：瓶蓋沒鎖緊，墨水變濃、變色，甚至結膜
- **滋生黴菌**：長期敞開、環境溫暖潮濕，表面可能長出綠黑黴膜
- **氧化變色**：部分染料接觸空氣久了色調改變
- **沉澱分層**：顏料墨特別常見，用前搖勻即可

## 開瓶後的儲存守則

正確儲存能讓一瓶好墨水陪伴你好幾年：

- **鎖緊瓶蓋**：每次用完確實轉緊，這是最重要的一條
- **陰涼避光**：放抽屜或墨架，避免窗邊日曬與高溫
- **直立存放**：瓶口朝上，避免側漏、避免長期浸潤瓶蓋內側
- **控制濕度**：太潮濕容易長黴，太乾燥又加速蒸發，室溫陰處最理想
- **別冰冰箱**：溫差凝結的水氣反而稀釋墨水，常溫即可

> 小知識：墨水瓶出現一層薄黴膜不代表整瓶報銷——小心撈掉表層、上層聞起來無異味的話，下層多半還能用；但若已發臭、整瓶混濁變色，就該丟棄了。

## 一支筆長期不用時的墨水處理

對鋼筆本身而言，「儲存」和墨水瓶一樣重要：若這支筆要放超過一個月，**先把墨水抽乾、用清水沖到乾淨，再晾乾收納**。把墨水管乾在筆裡，是日後堵筆、結晶與腐蝕的最常見起點。

## 常見問題

**Q：我可以把不同廠牌的黑色墨水互相混調嗎？**
A：同為染料系的黑色，相對安全，但仍建議先小量試、靜置觀察。不同廠牌的潤滑劑與防腐配方不同，多少有變數。

**Q：墨水放了好幾年還能用嗎？**
A：外觀清澈、聞起來無異味、試寫顏色正常，通常還能用。若已長黴、發臭、嚴重分層結塊，就別冒險灌進筆裡。

**Q：為什麼我的墨水表面長了一層彩虹薄膜？**
A：常是水分蒸發＋氧化在表面結的膜，輕者撈掉即可；若伴隨異味與混濁，表示已滋生微生物，建議丟棄。

**Q：混調出來的墨水可以存很久嗎？**
A：自製混調缺乏原廠防腐配方，通常建議短期內用完，別像新墨一樣放好幾年；存放時一樣要鎖緊、避光、直立。
