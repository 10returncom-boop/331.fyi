# 鐵膽墨水：經典配方與現代再興

在現代化學墨水問世之前，歐洲人寫了將近一千多年的正式文件，靠的都是同一種墨水——**鐵膽墨水（Iron Gall Ink）**。達文西、莫札特、美國憲法的手稿，背後都有它的身影。它寫下的字黑得深沉、防水耐久，乾透後幾乎與紙纖維融為一體。但它同時帶著一個迷人又危險的特質：會「鏽」。用對了是傳世墨，用錯了會咬壞筆。

## 什麼是鐵膽墨水

鐵膽墨水的核心原料，是**五倍子（Gallnut，一種被蜂蝨刺激長出的樹瘤）萃取出的鞣酸**，加上亞鐵鹽（硫酸亞鐵）。兩者混合後發生化學反應，生成「鞣酸亞鐵」——這東西剛寫到紙上時顏色淺淡，幾乎看不出來。

關鍵在後續：接觸空氣中的氧氣，鞣酸亞鐵逐漸氧化成**鞣酸鐵**，一種深藍黑色、不溶於水的沉澱。也就是說，鐵膽墨水的黑不是「立刻顯現」，而是隨時間慢慢氧化變黑。剛寫完偏灰，放幾個小時到幾天才轉為濃黑，這是它最迷人的特徵。

> 小知識：因為字跡是靠氧化沉澱「長」出來的，鐵膽墨水乾透後防水性極佳，且會牢牢咬進紙張——這也是古老手抄本歷經數百年仍清晰的原因。

## 歷史：從手抄本到鋼筆時代

鐵膽墨水的歷史幾乎與歐洲書寫史等長。中古世紀的僧侶以鵝毛筆蘸著自製鐵膽墨水抄寫聖經；大航海時代，水手用它在船上寫日誌；到了 19 世紀自來水鋼筆誕生，鐵膽墨水仍是文書主流之一。直到 20 世紀，化學穩定、使用便利的染料墨水興起，鐵膽墨水才逐漸退為小眾。近年隨著鋼筆復古風潮，它又重新回到玩家視野。

## 鐵膽墨水的優點

- **終極防水與耐久**：氧化成鞣酸鐵後，字跡耐水、耐光、不易褪色，存檔級表現
- **色澤沉穩黑亮**：隨時間氧化出的深黑，帶著染料墨難以模仿的層次
- **寫感滑順**：現代配方的鐵膽墨通常潤滑度佳，書寫感受細緻

## 代價：腐蝕與保養

鐵膽墨水最大的禁忌，在於它的酸性與含鐵本質：

- **偏酸性**：新鮮的鐵膽墨 pH 值偏酸，長期殘留可能腐蝕鋼筆內部金屬零件與彈性件
- **會結晶沉澱**：未反應完全的鐵鹽在筆內乾涸後，可能形成硬塊堵塞筆舌
- **必須勤洗**：鐵膽墨絕對不能長期待在筆裡不動，否則鏽蝕與堵塞風險大增

> 注意：鐵膽墨水對古董筆、內含橡膠或彈性金屬件的老上墨系統特別不友善。灌鐵膽墨的筆，建議選構造簡單、容易清洗的款式，並且每隔一兩週就徹底清洗一次。

## 使用鐵膽墨水的務實守則

| 守則 | 說明 |
| --- | --- |
| 專筆專用 | 保留一支專吃鐵膽墨的筆，別與珍貴收藏筆混用 |
| 勤於清洗 | 約 1–2 週即沖洗一次，避免鐵鹽長期殘留 |
| 勿長期待筆 | 超過一兩週不用，先把筆清空洗淨再收 |
| 避開敏感材質 | 古董橡膠上墨、易鏽金屬件的筆款要特別小心 |
| 與他墨分開 | 不要與染料、顏料墨水隨意混調 |

## 為什麼它現在又紅了

鐵膽墨水的現代再興，其實是鋼筆文化「從玩色回到玩質感」的一環。當玩家收集了一排五彩繽紛的染料墨之後，開始追求那種「寫下去、隔天再看它慢慢變黑」的時間感，以及乾透後與紙融為一體的沉穩黑。它不適合每天大量書寫，卻適合寫信、寫日記、蓋章存檔——把時間的沉澱，寫進紙裡。

## 常見問題

**Q：為什麼我用鐵膽墨水寫完顏色很淺？**
A：那是正常的。鐵膽墨剛上紙時是淺灰，需要接觸空氣氧化幾小時到幾天才會轉深黑。別以為沒墨而重寫，放著等它氧化即可。

**Q：鐵膽墨水真的會把筆弄壞嗎？**
A：長期殘留、不清洗才會。現代正規配方的鐵膽墨對一般鋼筆不算劇毒，但酸性與含鐵本質決定了它不能像染料墨那樣「灌了就放著」，勤洗是不變的鐵律。

**Q：鐵膽墨水和黑色顏料墨水哪個更防水？**
A：兩者都很防水。鐵膽墨乾透後咬進紙纖維，耐久度傳奇；顏料墨則是靠顆粒卡著。實務上書寫存檔用兩者皆可，差別在鐵膽墨會氧化變色、且更講保養。

**Q：鐵膽墨水可以寫在鋼筆專用紙以外的紙上嗎？**
A：可以，但吸收快的紙會讓它顯色更黑、更不透；粗糙紙則可能略暈。建議先在慣用紙上試寫，觀察它氧化後的實際色澤。
