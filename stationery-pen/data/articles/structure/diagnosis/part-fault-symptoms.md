# 零件故障對應症狀速查表

鋼筆出問題時，新手最容易直接歸因於「筆尖壞了」。但事實上，絕大多數毛病出在密封、筆舌、上墨系統或保養習慣上。這篇文章給你一張實用的速查表：看到什麼症狀、優先懷疑哪個零件、自己可以怎麼處理。請把它當作診斷的起點，而不是終判。

## 使用這張表的原則

- 先做「最便宜、最不侵入」的動作：清洗、更換墨水、更換紙張。
- 症狀對應的可能原因常有多個，由最常見（最上游）往最少見排。
- 若動到筆尖、筆舌拆裝等進階動作，請評估自己的技術與筆的價值，必要時交給專業維修。

## 症狀 → 可能原因 → 處理 速查表

| 症狀 | 可能原因 | 優先處理方式 |
| --- | --- | --- |
| 完全寫不出墨 | 墨囊未頂緊／吸墨器未真的吸到墨；儲墨腔無空氣補入 | 重新安裝墨囊、重新上墨、確認筆握進墨孔通暢 |
| 寫一半越來越乾、最後不出墨 | 筆舌通氣道堵塞；墨水乾涸結膜 | 溫水浸泡筆尖筆舌數小時，壓水龍頭讓水流通 |
| 第一筆飛白、多寫幾筆才順 | 筆蓋氣密不足、久置墨水乾掉；筆尖縫有結膜 | 蓋好筆蓋勤寫；輕柔劃玻璃或專用清潔 |
| 下墨過量、字跡暈開積墨 | 筆尖縫過寬；墨水過稀；筆舌貼合縫隙大 | 換乾性墨水、換不吸水紙；仍未改善請專業調校 |
| 刮紙、有沙沙聲或劃劃聲 | 銥粒打磨不良；筆尖兩翼高低不齊；紙張太粗 | 換鋼筆專用紙試試；仍刮紙請店家 Nib Tuning |
| 線條忽粗忽細、有橫紋 | 筆舌貼合歪斜；筆尖縫局部卡紙纖維 | 拆下筆尖重貼、清潔筆尖縫與筆舌頂面 |
| 筆蓋打開就滴水 | 儲墨腔密封不良；通氣道短路；高溫使空氣膨脹 | 避免高溫；檢查墨囊／O 圈；筆尖朝上攜帶 |
| 筆蓋內側一圈墨漬 | 書寫後未擦筆尖即蓋蓋；墨水沿筆尖回流 | 蓋蓋前用衛生紙輕拭筆尖周圍 |
| 墨囊漏墨、筆握處滲墨 | 墨囊老化龜裂；吸墨器密封圈失效 | 更換墨囊／吸墨器；檢查 O 圈 |
| 筆蓋鬆脫、轉不緊或插不緊 | 螺牙磨損；直插內襯磨耗 | 直插款可內側微貼膠帶；螺牙損傷需換件 |
| 筆尖歪向一邊、筆畫偏斜 | 跌落撞擊；筆尖兩翼受力不均 | 請專業筆尖矯正，勿自行扳 |
| 銥粒崩缺、有小缺口 | 撞擊桌面或掉落；長年磨耗 | 需重新焊接銥粒與打磨，送修 |
| 旋開筆握時螺牙緊澀 | 螺牙沾乾墨；長年未轉動 | 以溫水清潔螺牙、上少許矽脂潤滑 |
| 墨水出現怪味、混濁或沉澱 | 墨水過期；不同墨水殘留混調 | 全筆清洗、更換新墨水，勿繼續使用 |
| 同一支筆換墨後顏色怪、起渣 | 舊墨與新墨起化學反應；未洗乾淨 | 徹底清洗後再上新墨 |

> 提示：九成「筆尖問題」在清洗與更換墨水後就消失。先做這兩步，再考慮動筆。

## 快速分流：三個自我檢查

在對照上表之前，先做三個動作，能排除大部分迷因：

1. **溫水浸泡筆尖與筆舌 1–2 小時**，再以流水壓出舊墨，重新上墨試寫。
2. **換一瓶你確定好寫的水性墨水**（不要用試管小樣或奇怪配方）。
3. **換一張鋼筆專用紙**，不要用粗糙影印紙測試。

做完這三步，症狀若消失，問題就出在「髒、墨、紙」，與筆本身無關。

## 什麼時候該送修

出現以下狀況，建議交給專業，不要自己動手：
- 筆尖跌落後明顯歪斜或刮紙，自己喬不回
- 銥粒缺角、筆尖變形
- 活塞／真空上墨內部漏墨、轉不動
- 墨囊規格特殊、找不到相容零件
- 古董筆、高收藏價值筆款

> 注意：鋼筆維修多數不貴，但自己拆錯一個零件，代價可能是整支筆報銷。價值超過你心理門檻的筆，交給店家最穩。

## 常見問題

**Q：我怎麼知道是筆尖問題還是筆舌問題？**
A：下墨多寡、斷墨、飛白多半指向筆舌與供墨；刮紙、劃劃、筆畫偏斜多半指向筆尖。跨兩者的症狀（忽粗忽細）則常見於筆舌貼合不良。

**Q：清洗後還是斷墨，要不要繼續泡？**
A：可以。頑固沉積可用溫水泡半天到一天，中間換水；若懷疑是顏料墨結晶，可重複泡水、輕壓出墨。長者仍無改善，才考慮零件層面問題。

**Q：可以用牙刷刷筆舌溝嗎？**
A：不建議硬刷。筆舌是精細塑膠，硬毛刷會刮傷溝面。用溫水＋軟水壓即可，必要時用木牙籤（非金屬）輕挑異物。

**Q：這張表能診斷古董筆嗎？**
A：原理相通，但古董筆多了橡膠老化、原廠零件缺料等問題。症狀可對照，處理上建議直接找熟悉老筆的維修師傅。
